# Block Inventory

**Project:** nitroblocks
**Date:** 2026-04-13

## Local Blocks


| Block     | Purpose                                                                |
| --------- | ---------------------------------------------------------------------- |
| cards     | Grid layout of content items with images, headings, and descriptions   |
| columns   | Side-by-side content in 2+ columns for comparisons or layouts          |
| countdown | Timer/countdown display                                                |
| footer    | Site footer with navigation links, social media, and legal info        |
| fragment  | Reusable content section that can be embedded across pages             |
| header    | Site header with logo, navigation, and utility links                   |
| hero      | Large heading, text, and call-to-action buttons for page introductions |
| tabs      | Tabbed interface for organizing related content in switchable panels   |
