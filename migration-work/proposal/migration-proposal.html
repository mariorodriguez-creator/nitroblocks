Methodology

Design System

Pencil (.pen files) committed alongside code. Atomic structure: foundations → atoms → molecules → organisms → templates. CSS custom properties published to styles/styles.css. designlang drift enforces consistency vs. the source.

Block Development

Spec-Driven Development (SDD) via speckit per block. Each block runs through building-blocks + content-driven-development + eds-styles + eds-wcag + eds-analytics + eds-documentation skills. Lighthouse 100 enforced via PSI bot per PR.

Content Migration

Agentic batch via page-import skill, orchestrated by migration-content. 6 batches grouped by template family with human review checkpoint per batch. Redirect mapping + bulk metadata sheet published. Visual regression (designlang visual-diff) at the Phase-5 gate.
