Methodology

Design System

Pencil (.pen files) with normalized tokens. Atomic design: foundations → atoms → molecules → organisms → templates. CSS custom properties exported for styles.css.

Block Development

Spec-Driven Development (SDD) via speckit. Content-first: author-friendly content models before code. Block Collection consulted for reusable starting points.

Content Migration

Agentic batch via page-import skill. Template-grouped batches with human review checkpoints. SEO redirect mapping. Visual regression at each gate.
